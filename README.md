# The Serpent’s Breath: Escape from Chichén Itzá

Digital escape room build using the Pelican template structure.

## Core features
- 5-minute cinematic backstory briefing
- 30-minute oxygen countdown
- Torch toggle: torch on reveals the clue concept but drains oxygen faster
- Wrong checkpoint/path choices add oxygen penalties
- Mayan-inspired carvings, translations, sculptures, airflow, shadows, balance, echo, and astronomy clues
- RSVP, access-code, host dashboard, check-in, sponsor popup, and player screens retained from the template

## Run locally
```bash
npm install
npm start
```

Open `/host/` for the host screen and `/player/` for players.
